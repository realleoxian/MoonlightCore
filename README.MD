## What is MoonlightCore?

Moonlight core is a layer abstraction of Minecraft mod loaders like fabric, forge and neoforge that is aimed to help the multi-loader mod developers of Minecraft utilities for their mods.

**THIS MOD IS A LIBRARY AND DOESN'T ADD ANYTHING BY ITSELF**

### Features

1. Configuration
    - Configuration Synchronization
2. Event
3. Networking
4. Registry
5. World generation
    - World surface modification
    - Biome addition
